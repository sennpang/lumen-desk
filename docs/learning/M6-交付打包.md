## 核心知识点

### 1. asarUnpack：原生模块打包第一大坑

asar 是把源码打成一个归档文件，Electron 做了虚拟文件系统让 `require` 能读里面的 JS。但 `.node` 文件是**动态链接库**，要按真实文件路径 `dlopen` 加载——虚拟路径无法被动态链接器识别，留在 asar 里必崩。

```yaml
asarUnpack:
  - "**/node_modules/better-sqlite3/**"
  - "**/node_modules/hnswlib-node/**"
```

builder 会把它们原样放到 `app.asar.unpacked/` 并在 asar 内留解包标记，`require` 自动重定向。M6 的验证不是"打包成功"就算完——用包内 Node 直接 `require('app.asar/node_modules/better-sqlite3')` 跑了内存库读写、hnswlib 建索引检索 5 项断言，确认真能加载。

### 2. ABI 重编译为什么是必须的

Electron 内置的 Node 与系统 Node 的 `NODE_MODULE_VERSION`（ABI）可能不同。原生 C++ 插件按某个 ABI 编译，运行时 ABI 不匹配直接拒绝加载。`postinstall: electron-builder install-app-deps` 与打包时的 `@electron/rebuild` 都在干同一件事：针对 Electron 的头文件重编译原生模块。

### 3. 生产环境安全收敛（与开发态的区别对待）

在 [src/main/index.ts](../../src/main/index.ts)：

- **单实例锁** `requestSingleInstanceLock()`：第二次启动直接退出；`second-instance` 时唤起/聚焦已有窗口——否则两个实例抢同一个 SQLite、重复跑后台任务
- **导航拦截** `will-navigate`：单页壳应用拒绝任何整页导航，http(s) 外链转 `shell.openExternal`，`file:`/`javascript:` 等静默拦截
- **打包态收敛**：`app.isPackaged` 时移除默认菜单（含重新加载/DevTools 项）、`webPreferences.devTools=false`。开发态全部保留，调试不受影响
- 新窗口 `setWindowOpenHandler` 也有协议白名单（M5 Agent 的 open_url 白名单之外的第二道闸）

原则：**用 `app.isPackaged` 区分行为，而不是维护两套代码。**

### 4. 未签名应用的分发现实

没有 Apple Developer 账号时 `mac.identity: null` 显式跳过签名，产出 ad-hoc 包，可本机/内网分发。用户首次打开需右键 → 打开（或系统设置里允许），dmg 里放 Applications 软链做拖拽安装。将来要正式分发，再补 Developer ID 签名 + 公证（notarization），配置增量即可。

### 5. 设置备份：密钥为什么不导出

备份文件是 `{kind, appVersion, exportedAt, settings, hasApiKey}` 的 JSON。API Key 由 safeStorage 绑**机器级密钥**加密（Keychain/DPAPI），换机器根本无法解密——导出既无用又是泄露面，只记录"原机器上是否配过 Key"，导入后提示重新填写。

导入链路对外部文件零信任：先验 `kind` 防误选其他 JSON，再经 `sanitizeSettings` 逐字段按类型/枚举校验、只挑已知键、缺字段回退默认值。

### 6. 首次引导的状态设计

不新建表：在 `app_setting` key-value 表加一个 `ui_meta` 行存 `onboardingDismissedAt`。启动时为 null 就弹三步卡（配模型 → 导入资料 → 三种对话模式）。任何退出路径（开始使用/快捷跳转）都先持久化 dismiss 再跳转；查询失败则降级为不弹，引导永远不能挡住主界面。

### 7. 应用图标怎么做才不"AI 模板感"

最终方案（用户审美主导两轮筛选）：[resources/icon.svg](../../resources/icon.svg) 暖墨黑 squircle + 米白圆头粗笔字母 L（竖笔即灯柱）+ 顶端琥珀灯点。刻意不用渐变/光晕/星光。

工程要点：

- **小尺寸优先**：Dock 16px 下只有强对比几何笔画还可辨，复杂场景（书+灯+光）缩到 32px 必糊
- macOS 零三方工具链：SVG 用系统 Swift `NSImage`（11+ 原生支持 SVG）→ `NSBitmapImageRep` 出各尺寸 PNG → `iconutil -c icns` 组 iconset（16~512@2x）
- builder 按 `buildResources: resources` 约定自动拾取 `icon.icns`/`icon.png`，改完图标重跑 `npm run dist`

## 打包后的验证清单（下次发版照做）

1. `npm run typecheck` + `npm run build` 通过
2. `npm run dist` 产出 dmg + zip；`@electron/rebuild` 两个原生模块均 finished
3. `app.asar.unpacked/` 下能看到两个 `.node`（含 darwin-arm64 prebuild）
4. 用**包内**二进制 `ELECTRON_RUN_AS_NODE=1` 跑断言：better-sqlite3 内存库读写、hnswlib 建索引检索、主/渲染产物存在
5. 直接启动 `.app/Contents/MacOS/...` 存活（initDb 同步加载原生库不崩）
6. `hdiutil attach` 挂载 dmg，确认含 app + Applications 软链
7. Finder/Dock 若显示旧图标，是图标缓存：`killall Finder; killall Dock`
